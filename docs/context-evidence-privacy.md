# Model context and evidence

The configured provider receives the bounded page representation and action
choices needed for the current task. Page labels, destinations and text are
untrusted data. They cannot grant admission or change the requested goal.

Sensitive form controls are excluded from ordinary choices and provider state.
Known field text should be supplied through `values`. The runner checks requested
blocked literals before transferring context or retaining its corresponding
public result. Privacy checks add a local boundary around the selected context.

Review the provider route, endpoint and stored credential before using a private
site. Existing Chrome shares its selected browser account. Page text can contain
sensitive material outside known controls or blocked literals.

Functional check reports and bounded geometry are retained as local artifacts.
Unsafe pixels are withheld, and visual diagnostics report their own incomplete
state. Access artifacts using the server's returned ID and range metadata.
Inspect evidence before sharing it with another party.
