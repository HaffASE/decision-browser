# Support

Use [GitHub issues](https://github.com/HaffASE/decision-browser/issues) for
reproducible bugs and feature requests. Decision Browser is experimental, and
support has no promised response time.

Start with [installation](docs/installation.md), [providers](docs/providers.md)
and [verification](docs/verification.md). Include the executable version or
commit, operating system, browser version, coding-client version, failed stage
and a reproduction on an owned page. `decision-browser doctor --json` and
`install-status --json` inspect local setup.

Review diagnostics before sharing. Omit keys, cookies, complete client settings,
private URLs, screenshots and account data. Use [SECURITY.md](SECURITY.md) for
suspected vulnerabilities.
