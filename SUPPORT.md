# Support

Decision Browser is experimental. Use [GitHub issues](https://github.com/HaffASE/decision-browser/issues)
for reproducible bugs and feature requests when you have access to the repository.
There is no guaranteed support response time or long-term maintenance commitment.

Start with [installation](docs/installation.md), [providers](docs/providers.md)
and [verification](docs/verification.md). For setup problems, include the package
version or commit, operating system, Python/uv/client versions, failed stage, and
a minimal owned-page reproduction. State whether the failure is in setup, MCP
loading, human admission, a provider request, or browser verification.

Review diagnostics before sharing them. Do not include keys, cookies, complete
client configuration, private URLs, screenshots or account data. Report suspected
vulnerabilities using [SECURITY.md](SECURITY.md), not a public bug report.
